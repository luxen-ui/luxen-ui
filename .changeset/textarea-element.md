Add a `.l-textarea` style for native `<textarea>` controls. A bare `<textarea>` inside `l-form-field` is auto-styled (no class needed); `data-size` (`xs`–`xl`) sets the height and `data-resize` (`vertical`, `none`, `both`, `auto`) controls the resize handle, with `auto` growing the box to fit its content.
