Add `<l-prose-editor>`, a form-associated rich text editor built on Tiptap (ProseMirror). It ships a configurable toolbar (`toolbar-preset` or a custom `toolbar` list), top/bottom placement, placeholder and initial HTML/JSON content, a lazy-loaded emoji picker, and submits its HTML value inside a `<form>`. Import the editable-content styles once globally with `@import 'luxen-ui/css/prose-editor';`.
