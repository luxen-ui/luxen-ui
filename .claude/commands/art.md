# Art Text Command

Convert text to regional indicator symbols (squared letters).

## Usage

Convert the provided text to use regional indicator Unicode symbols that look like squared letters.

## Conversion Rules

- A-Z → 🅰-🆉 (regional indicator symbols)
- Numbers and special characters remain unchanged
- Hyphens remain as hyphens
- Spaces remain as spaces

## Examples

- "wa-drawer" → "🆆🅰-🅳🆁🅰🆆🅴🆁"
- "wa-dialog" → "🆆🅰-🅳🅸🅰🅻🅾🅶"
- "hello world" → "🅷🅴🅻🅻🅾 🆆🅾🆁🅻🅳"

Convert the text provided by the user to this stylized format.
